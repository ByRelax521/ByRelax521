# BLOOM / JARVIS V4.6.2

BLOOM, formerly JARVIS V4, is a Gemini Live desktop assistant with a React/Vite HUD. The source snapshot and current test notes are in [`bloom/`](bloom/README.md).

> Important: this repository contains a recovered/partial source snapshot, not a complete, reproducible desktop release. See the scope and test limitations in the project guide before attempting to build the Windows/macOS app.

## Quick checks

```bash
cd bloom/web_hud
npm ci
npm run build
npm run lint
```

The HUD expects the desktop Python backend for `/api/*` features. See [`bloom/README.md`](bloom/README.md) for details, Python tests, and next steps.
